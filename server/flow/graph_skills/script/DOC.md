# 脚本

脚本模块负责定义和执行脚本，并提供日志与提示能力。

## 使用建议

- 脚本适合封装多步逻辑、复杂计算或现有节点难以表达的动作。
- 普通线性流程优先使用图节点表达，脚本用于补足图节点表达力。
- Go 重构版使用 `script/js` + `script/js_exec`，不再提供 Python 执行节点。
- AI 搭建时，只有遇到循环、重复 UI 操作、组合判断、变量计算或连线明显复杂时，才优先生成脚本节点。
- 设备、模板图片、mask、OCR、文本、数值和布尔配置应通过执行节点动态入参传入脚本，避免在代码里硬编码资源。
- 业务判断失败优先用 `setResult('ok', false)` 输出，再连接「断言」和「测试结果」；异常只用于意外错误。
- 生成脚本不要使用文件、网络、系统命令、`subprocess`、`eval`、`exec` 或安装依赖等非测试流程能力。
- 日志和提示节点适合让生成流程的中间状态更容易调试。
